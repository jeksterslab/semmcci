## Description

Monte Carlo confidence intervals for free and defined parameters in
models fitted in the structural equation modeling package `lavaan` can
be generated using the `semmcci` package. `semmcci` has three main
functions, namely,
[`MC()`](https://jeksterslab.github.io/semmcci/reference/MC.md),
[`MCMI()`](https://jeksterslab.github.io/semmcci/reference/MCMI.md), and
[`MCStd()`](https://jeksterslab.github.io/semmcci/reference/MCStd.md).
The output of `lavaan` is passed as the first argument to the
[`MC()`](https://jeksterslab.github.io/semmcci/reference/MC.md) function
or the
[`MCMI()`](https://jeksterslab.github.io/semmcci/reference/MCMI.md)
function to generate Monte Carlo confidence intervals. Monte Carlo
confidence intervals for the standardized estimates can also be
generated by passing the output of the
[`MC()`](https://jeksterslab.github.io/semmcci/reference/MC.md) function
or the
[`MCMI()`](https://jeksterslab.github.io/semmcci/reference/MCMI.md)
function to the
[`MCStd()`](https://jeksterslab.github.io/semmcci/reference/MCStd.md)
function. The functions
[`MCGeneric()`](https://jeksterslab.github.io/semmcci/reference/MCGeneric.md),
[`MCFunc()`](https://jeksterslab.github.io/semmcci/reference/MCFunc.md),
and [`Func()`](https://jeksterslab.github.io/semmcci/reference/Func.md)
generate Monte Carlo confidence intervals for functions of parameters
when the estimates and their sampling covariance matrix are supplied. A
description of the package and code examples are presented in Pesigan
and Cheung (2024,
[doi:10.3758/s13428-023-02114-4](https://doi.org/10.3758/s13428-023-02114-4)).

In the Monte Carlo method, a sampling distribution of parameter
estimates $`\hat{\boldsymbol{\theta}}^{\ast}`$ is generated from the
multivariate normal distribution using the parameter estimates
$`\hat{\boldsymbol{\theta}}`$ and the corresponding sampling
variance-covariance matrix
$`\widehat{\mathrm{Var}} \left( \hat{\boldsymbol{\theta}} \right)`$,

``` math
\hat{\boldsymbol{\theta}}^{\ast} \sim \mathcal{N} \left( \hat{\boldsymbol{\theta}}, \widehat{\mathrm{Var}} \left( \hat{\boldsymbol{\theta}} \right) \right) .
```

Confidence intervals for defined parameters
$`\boldsymbol{g} \left( \hat{\boldsymbol{\theta}} \right)`$ are
generated by obtaining percentiles corresponding to
$`100 \left( 1 - \alpha \right) \%`$ from the generated sampling
distribution, where $`\alpha`$ is the significance level.

## Example

A common application of the Monte Carlo method is to generate confidence
intervals for the indirect effect. In the simple mediation model,
variable `X` has an effect on variable `Y`, through a mediating variable
`M`. This mediating or indirect effect is a product of path coefficients
from the fitted model.

\
[`library`](https://rdrr.io/r/base/library.html)`(``package ``=`` ``semmcci``)`\
[`library`](https://rdrr.io/r/base/library.html)`(``package ``=`` ``lavaan``)`

### Data

\
[`summary`](https://rdrr.io/r/base/summary.html)`(``object ``=`` ``df``)`\
`#>        X                  M                   Y            `\
`#>  Min.   :-2.82180   Min.   :-3.130071   Min.   :-2.912288  `\
`#>  1st Qu.:-0.64989   1st Qu.:-0.691253   1st Qu.:-0.687495  `\
`#>  Median : 0.03282   Median :-0.008392   Median : 0.005957  `\
`#>  Mean   : 0.02303   Mean   : 0.004328   Mean   : 0.003421  `\
`#>  3rd Qu.: 0.71382   3rd Qu.: 0.680563   3rd Qu.: 0.719463  `\
`#>  Max.   : 3.09723   Max.   : 2.863601   Max.   : 2.977578  `\
`#>  NAs    :100        NAs    :100         NAs    :100`

### Model Specification

The indirect effect is defined by the product of the slopes of paths `X`
to `M` labeled as `a` and `M` to `Y` labeled as `b`. In this example, we
are interested in the confidence intervals of `indirect` defined as the
product of `a` and `b` using the `:=` operator in the `lavaan` model
syntax.

\
`model`` ``<-`` ``"`\
`  Y ~ cp * X + b * M`\
`  M ~ a * X`\
`  X ~~ X`\
`  indirect := a * b`\
`  direct := cp`\
`  total := cp + (a * b)`\
`"`

### Monte Carlo Confidence Intervals

We can now fit the model using the
[`sem()`](https://rdrr.io/pkg/lavaan/man/sem.html) function from
`lavaan`. We use full-information maximum likelihood to deal with
missing values.

\
`fit`` ``<-`` ``lavaan``::`[`sem`](https://rdrr.io/pkg/lavaan/man/sem.html)`(``data ``=`` ``df``, model ``=`` ``model``, missing ``=`` ``"fiml"``)`

The `fit` `lavaan` object can then be passed to the
[`MC()`](https://jeksterslab.github.io/semmcci/reference/MC.md) function
to generate Monte Carlo confidence intervals.

\
`mc`` ``<-`` `[`MC`](https://jeksterslab.github.io/semmcci/reference/MC.md)`(``lav ``=`` ``fit``, R ``=`` ``20000L``, alpha ``=`` ``0.05``)`\
`mc`\
`#> Monte Carlo Confidence Intervals`\
`#>              est     se     R    2.5%  97.5%`\
`#> cp        0.2166 0.0307 20000  0.1573 0.2773`\
`#> b         0.5553 0.0293 20000  0.4974 0.6124`\
`#> a         0.5489 0.0294 20000  0.4916 0.6062`\
`#> X~~X      0.9866 0.0459 20000  0.8967 1.0768`\
`#> Y~~Y      0.5214 0.0255 20000  0.4712 0.5717`\
`#> M~~M      0.7446 0.0360 20000  0.6741 0.8144`\
`#> Y~1      -0.0123 0.0247 20000 -0.0608 0.0356`\
`#> M~1       0.0001 0.0289 20000 -0.0567 0.0573`\
`#> X~1       0.0237 0.0326 20000 -0.0402 0.0873`\
`#> indirect  0.3048 0.0228 20000  0.2617 0.3507`\
`#> direct    0.2166 0.0307 20000  0.1573 0.2773`\
`#> total     0.5214 0.0291 20000  0.4649 0.5788`

### Monte Carlo Confidence Intervals - Multiple Imputation

The [`MCMI()`](https://jeksterslab.github.io/semmcci/reference/MCMI.md)
function can be used to handle missing values using multiple imputation.
The [`MCMI()`](https://jeksterslab.github.io/semmcci/reference/MCMI.md)
accepts the output of
[`mice::mice()`](https://amices.org/mice/reference/mice.html),
[`Amelia::amelia()`](https://rdrr.io/pkg/Amelia/man/amelia.html), or a
list of multiply imputed data sets. In this example, we impute
multivariate missing data under the normal model.

\
`mi`` ``<-`` ``mice``::`[`mice`](https://amices.org/mice/reference/mice.html)`(`\
`  data ``=`` ``df``,`\
`  method ``=`` ``"norm"``,`\
`  m ``=`` ``100``,`\
`  print ``=`` ``FALSE``,`\
`  seed ``=`` ``42`\
`)`

We fit the model using lavaan using the default listwise deletion.

\
`fit`` ``<-`` ``lavaan``::`[`sem`](https://rdrr.io/pkg/lavaan/man/sem.html)`(``data ``=`` ``df``, model ``=`` ``model``)`

The `fit` `lavaan` object and `mi` object can then be passed to the
[`MCMI()`](https://jeksterslab.github.io/semmcci/reference/MCMI.md)
function to generate Monte Carlo confidence intervals.

\
`mcmi`` ``<-`` `[`MCMI`](https://jeksterslab.github.io/semmcci/reference/MCMI.md)`(``lav ``=`` ``fit``, mi ``=`` ``mi``, R ``=`` ``20000L``, alpha ``=`` ``0.05``, seed ``=`` ``42``)`\
`mcmi`\
`#> Monte Carlo Confidence Intervals (Multiple Imputation Estimates)`\
`#>             est     se     R   2.5%  97.5%`\
`#> cp       0.2167 0.0309 20000 0.1568 0.2764`\
`#> b        0.5534 0.0306 20000 0.4936 0.6136`\
`#> a        0.5484 0.0297 20000 0.4902 0.6069`\
`#> X~~X     0.9868 0.0460 20000 0.8969 1.0773`\
`#> Y~~Y     0.5220 0.0259 20000 0.4714 0.5730`\
`#> M~~M     0.7443 0.0351 20000 0.6751 0.8126`\
`#> indirect 0.3035 0.0234 20000 0.2586 0.3503`\
`#> direct   0.2167 0.0309 20000 0.1568 0.2764`\
`#> total    0.5202 0.0296 20000 0.4619 0.5787`

## Other Features

The package provides the following functions.

| Function | Purpose |
|----|----|
| [`MC()`](https://jeksterslab.github.io/semmcci/reference/MC.md) | Monte Carlo confidence intervals from a `lavaan` model |
| [`MCMI()`](https://jeksterslab.github.io/semmcci/reference/MCMI.md) | Monte Carlo confidence intervals from a `lavaan` model fitted to multiply imputed data |
| [`MCStd()`](https://jeksterslab.github.io/semmcci/reference/MCStd.md) | Monte Carlo confidence intervals for the standardized estimates |
| [`MCGeneric()`](https://jeksterslab.github.io/semmcci/reference/MCGeneric.md) | Monte Carlo confidence intervals for defined parameters of any fitted model with [`coef()`](https://rdrr.io/r/stats/coef.html) and [`vcov()`](https://rdrr.io/r/stats/vcov.html) methods |
| [`MCFunc()`](https://jeksterslab.github.io/semmcci/reference/MCFunc.md) | Monte Carlo confidence intervals for a function of supplied estimates and their sampling covariance matrix |
| [`Func()`](https://jeksterslab.github.io/semmcci/reference/Func.md) | Confidence intervals for a function of a supplied sampling distribution |

The [`coef()`](https://rdrr.io/r/stats/coef.html),
[`vcov()`](https://rdrr.io/r/stats/vcov.html),
[`confint()`](https://rdrr.io/r/stats/confint.html),
[`summary()`](https://rdrr.io/r/base/summary.html), and
[`print()`](https://rdrr.io/r/base/print.html) methods are available for
the returned objects. Examples for each function are in the package
vignettes.
